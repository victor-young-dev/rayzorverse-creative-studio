# RayzorVerse Creative Video Skill

## Purpose
Create original, polished, visually rich promotional videos for RayzorVerse and its divisions, combining code-driven motion graphics and optional AI-generated assets.

## Required workflow
1. Identify campaign goal, audience, platform and call to action.
2. Analyze reference for motion, pacing, readability and visual hierarchy; do not copy third-party branding.
3. Storyboard hooks, beats, transitions and sound cues.
4. Produce 9:16 prototype with RayzorVerse brand presets.
5. Test on Android, with and without sound.
6. Evaluate: hook, graphics, readability, brand fit, movement, audio, CTA (1–5 each).
7. Iterate; record what worked and what did not.
8. Approve versioned template; update this skill only with tested lessons.

## Default specifications
1080×1920, 30fps, H.264 MP4 + AAC for final social video; keep text within safe margins, use original assets, check audio levels and licensing. Prototype WebM is not final MP4.

## Brand divisions
RayzorVerse, Rayzor Labs, BrandiLux, Apex Wright Lab, HexaGuild, African Venture Studio.

## First approved concept
Template 001: Kinetic Pendulum. Strong swinging emblem, question-to-payoff typography, blue/navy lighting. The implementation in this repository is an experimental browser recreation, not the original rendered MP4 project.

## Improvements under test
Better branded emblem, division-specific visual assets, richer cinematic depth, restrained motion, synchronized sound, remote rendering and AI footage when available.
