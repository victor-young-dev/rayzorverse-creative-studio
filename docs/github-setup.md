# GitHub and deployment

Repository: victor-young-dev/rayzorverse-creative-studio.

Use GitHub Pages (Settings → Pages → Deploy from branch) or import repository into Vercel as a static website. Entry point is root index.html; no build command is required.

**Privacy:** Repository was observed as public when first connected. To make it private, go to Settings → General → Danger Zone → Change repository visibility. Review GitHub Pages visibility implications first.

Do not commit API secrets, customer data, copyrighted reference footage or private tokens. Existing RayzorVerse website repositories are separate and must remain untouched.
