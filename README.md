# RayzorVerse Creative Studio 🎬

A mobile-first, experimental creative production studio for **RayzorVerse** and its divisions: Rayzor Labs, BrandiLux, Apex Wright Lab, HexaGuild, and African Venture Studio.

**Status:** v0.1 prototype. Built to turn ideas into branded motion graphics, reusable templates, experiments and an evolving production skill library.

## What works today
- Responsive browser studio and 9:16 animation preview
- Editable promotional hook, payoff, division, speed and accent color
- Template 001: Kinetic Pendulum (approved as a reusable concept)
- Browser WebM recording where Canvas capture and MediaRecorder are supported
- Documented architecture, roadmap, experiment log and SKILL.md

## Try it
Open `index.html` in a browser or deploy as a static site using GitHub Pages or Vercel. No installation, API key or build step is required.

**Note:** Browser recording may not work on all Android browsers. WebM is not MP4; remote MP4 rendering is a future milestone. AI video generation is **not yet connected**.

## Repository layout
- `index.html` — mobile-first studio
- `src/` — styles and browser animation logic
- `templates/catalog.json` — versioned template registry
- `docs/architecture.md` — hybrid AI/programmatic design
- `docs/roadmap.md` — development milestones
- `docs/skills/SKILL.md` — living production instructions
- `docs/experiments/` — testing and feedback records

## Creative workflow
**Reference → Concept → Prototype → Review → Iterate → Approve template → Update SKILL.md**

## Roadmap
